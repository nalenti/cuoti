第 37 页《11.2 完全平方公式（2）》的逐题批改与详细解析如下：
【知识梳理】
两数和（或差）的平方，等于这两个数的平方的和加上（或减去）它们的积的两倍。
即 $(a+b)^2 = a^2 + 2ab + b^2$ 或 $(a-b)^2 = a^2 - 2ab + b^2$。
【基础检测】
* 1. $(x+2)^2 =$ $x^2 + 4x + 4$ ✔️ 正确
* 2. $(-x+2y)^2 =$ $x^2 - 4xy + 4y^2$ ✔️ 正确
* 3. $(-x-2y)^2 =$ $x^2 + 4xy + 4y^2$ ✔️ 正确
* 4. $(a+b-c)(a-b+c) = ($ $a$ $)^2 - ($ $b-c$ $)^2$
   * 卷面批改： 卷面未做 ❌
   * 解析：
使用添括号分组法：
$a+b-c = a + (b-c)$
$a-b+c = a - (b-c)$
根据平方差公式得：$[a + (b-c)][a - (b-c)] = a^2 - (b-c)^2$。
   * 正确答案： $a$ ； $b-c$
   * 5. 已知 $x+y=2, xy=1$，则 $(x-y)^2 =$ $0$
   * 卷面批改： 卷面未做 ❌
   * 解析：
运用完全平方公式的变形关系：
$$(x-y)^2 = (x+y)^2 - 4xy$$
代入已知数据：
$$(x-y)^2 = 2^2 - 4 \times 1 = 4 - 4 = 0$$
   * 正确答案： $0$
6. 计算：
      * (1) $(-a-2b)^2$
      * 卷面批改： 中间步骤书写有误（加号写成提负号遗漏），最终结果错在系数 ❌
      * 解析：
      * 方法一（化负为正）：$(-a-2b)^2 = [-(a+2b)]^2 = (a+2b)^2 = a^2 + 4ab + 4b^2$
      * 方法二（按公式展开）：$(-a)^2 + 2(-a)(-2b) + (-2b)^2 = a^2 + 4ab + 4b^2$
      * 正确答案： $a^2 + 4ab + 4b^2$
      * (2) $\left(y - \frac{1}{2}\right)^2$
      * 卷面解答： $= y^2 - y + \frac{1}{4}$ ✔️ 正确
      * (3) $(-x^2 + 2y)^2$
      * 卷面解答： $= x^4 - 4x^2y + 4y^2$ ✔️ 正确
      * (4) $88^2$
      * 卷面批改： 拆项与计算均错 ❌
      * 错因分析： 卷面把 $88$ 拆成了 $(80+8)$，导致后续计算大数乘法时算错；通常用“简便计算”时，应拆成接近整十整百的差值。
      * 独立推导：
$$\text{原式} = (90 - 2)^2 = 90^2 - 2 \times 90 \times 2 + 2^2$$
$$= 8100 - 360 + 4 = 7744$$
(注：若按 $(80+8)^2 = 6400 + 1280 + 64 = 7744$ 计算，答案也为 7744，卷面最后算错是因为 $6400+1280=7680$，加 64 应为 7744，卷面上抄错/算成了 7744 以外的数字或中间步骤逻辑不清)
      * 正确答案： $7744$（建议写成 $(90-2)^2$ 更简便）
